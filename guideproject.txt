1. ОБЩЕЕ ОПИСАНИЕ
================================================================================

Проект "Resume" — это персональный веб-сайт-резюме, разработанный для 
публикации профессионального профиля специалиста Evan Effie (Lead Software 
Engineer & Lead Support Engineer). Сайт представляет собой одностраничное 
приложение с минималистичным дизайном в стиле Apple (наименование "mimalism").

2. АРХИТЕКТУРА ПРОЕКТА
================================================================================

2.1 Стек технологий
--------------------------------------------------------------------------------
- Фреймворк:        Nuxt.js 3.x (SSR/SSG фреймворк на базе Vue 3)
- Язык программирования: TypeScript
- CSS препроцессор: SCSS
- CSS:             Vanilla CSS с CSS-переменными
- Маршрутизация:   Vue Router (встроен в Nuxt)
- Шаблонизация:    Vue 3 Composition API
- Контент:         JSON файл (единый источник данных)

2.3 Компонентная архитектура
--------------------------------------------------------------------------------
Проект использует модульную архитектуру с разделением на:

  Секции (components/sections/):
  ├── ResumeHeader.vue      - Шапка с именем и должностями
  ├── ResumeFooter.vue      - Подвал с копирайтом
  ├── ContactsSection.vue   - Секция контактов
  ├── SkillsSection.vue     - Секция навыков
  ├── ExperienceSection.vue - Секция опыта работы
  ├── EducationSection.vue  - Секция образования
  └── ProjectsSection.vue   - Секция проектов

  UI-компоненты (components/ui/):
  ├── SkillTag.vue         - Тег навыка
  ├── ExperienceItem.vue   - Карточка опыта работы
  ├── ProjectItem.vue      - Карточка проекта
  └── DecorativeDivider.vue - Декоративный разделитель между секциями

  Паттерн использования:
  - Данные загружаются через useResumeData() composable
  - Компоненты получают данные через props
  - Все текстовые данные берутся из content/resume-content.json

2.4 Конфигурация Nuxt (nuxt.config.ts)
--------------------------------------------------------------------------------
- CSS: mimalism-styles.css и mimalism-global.scss
- Meta: title, description, charset, viewport, theme-color
- DevTools: включены
- Compatibility Date: 2025-07-15

2.5 Стилевая система (mimalism)
--------------------------------------------------------------------------------
mimalism-styles.css:
- CSS-переменные с префиксом --mimalism-*
- Цветовая схема (Apple-подобная)
- Система тёмной темы через prefers-color-scheme
- Анимации: mimalismFadeIn, mimalismFadeInUp с задержками
- Классы с префиксом .mimalism-*
- Адаптивная вёрстка (mobile-first)
- Print-стили

mimalism-global.scss:
- Layout (.mimalism-main, .mimalism-container)
- Utilities (.mt-6)
- Smooth scrolling
- Custom scrollbar
- Accessibility focus styles
- Print overrides

3.1 Файл контента
--------------------------------------------------------------------------------
Расположение: content/resume-content.json

Структура JSON:
{
  "personal": {
    "name": "Имя специалиста",
    "titles": ["Должность 1", "Должность 2"]
  },
  "contacts": [
    { "type": "email|telegram|github|linkedin", "label": "...", "value": "...", "href": "..." }
  ],
  "skills": ["Навык 1", "Навык 2", ...],
  "experience": [
    { "id": "...", "title": "...", "company": "...", "period": "...", "description": "..." }
  ],
  "education": { "institution": "..." },
  "projects": [
    { "id": "...", "name": "...", "technologies": "...", "year": "...", "description": "..." }
  ],
  "sections": {
    "contacts": "Название секции",
    "skills": "Название секции",
    "experience": "Название секции",
    "education": "Название секции",
    "projects": "Название секции"
  },
  "footer": {
    "copyright": "Текст копирайта"
  }
}

3.2 Как редактировать контент
--------------------------------------------------------------------------------
1. Открыть content/resume-content.json
2. Изменить нужные поля
3. Сохранить файл
4. Страница автоматически обновится (в dev режиме)
