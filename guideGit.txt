 Основные команды Git в терминале

  • Проверить состояние репозитория
    • git status
  • Добавить файлы в индекс (staging)
    • git add имя_файла
    • git add . — добавить всё
  • Создать коммит
    • git commit -m "сообщение коммита"
  • Посмотреть историю коммитов
    • git log
    • git log --oneline --graph --all
  • Посмотреть отличия
    • git diff — изменения в файлах
    • git diff --staged — изменения, уже добавленные в индекс
  • Посмотреть список веток
    • git branch
  • Создать ветку и перейти в неё
    • git branch имя_ветки
    • git checkout имя_ветки
    • или одной командой: git checkout -b имя_ветки
  • Переключиться на ветку
    • git checkout имя_ветки
    • (новый синтаксис) git switch имя_ветки
  • Подтянуть изменения с удалённого репо
    • git pull
    • git pull origin имя_ветки
  • Отправить коммиты на удалённый репо
    • git push
    • git push origin имя_ветки
  • Связать локальную ветку с удалённой (первый пуш)
    • git push -u origin имя_ветки
  • Клонировать репозиторий
    • git clone URL
  • Отменить изменения в файле (вернуть как в последнем коммите)
    • git checkout -- имя_файла (старый синтаксис)
    • git restore имя_файла (новый синтаксис)
  • Убрать файл из индекса (оставив изменения в рабочей директории)
    • git reset HEAD имя_файла
