1. КАК ЗАПУСТИТЬ АГЕНТА
================================================================================

1.1 Запуск в терминале
--------------------------------------------------------------------------------
opencode

или с указанием проекта:
opencode /путь/к/проекту

1.2 Полезные флаги
--------------------------------------------------------------------------------
opencode --help           # Справка
opencode --info           # Информация о системе

3. КАК ОБЩАТЬСЯ С АГЕНТОМ
================================================================================

3.1 Хорошие примеры
--------------------------------------------------------------------------------
✅ "Запусти npm run dev и проверь что сервер работает"
✅ "Добавь в resume-content.json новый навык 'Python'"
✅ "Создай компонент ContactForm для секции контактов"
✅ "Поменяй во всех файлах классы с old- на new-"
✅ "Обнови title в nuxt.config.ts на 'Мое резюме'"

3.2 Плохие примеры (избегай)
--------------------------------------------------------------------------------
❌ "Сделай красиво"           → "Добавь градиент в header"
❌ "Улучши сайт"              → "Оптимизируй загрузку изображений"
❌ "Что-то не работает"        → "Ошибка 404 на /images/logo.png"

3.3 Уточнение задач
--------------------------------------------------------------------------------
Если агент не понял:
- Уточни путь к файлу
- Опиши что ожидаешь увидеть
- Разбей задачу на части

6. ВАЖНЫЕ ОСОБЕННОСТИ АГЕНТА
================================================================================

6.1 Агент умеет
--------------------------------------------------------------------------------
✓ Читать файлы
✓ Создавать и редактировать файлы
✓ Запускать npm/terminal команды
✓ Перезапускать dev-сервер
✓ Понимает TypeScript, Vue, JSON, CSS
✓ Работает с git

6.2 Агент не умеет (пока)
--------------------------------------------------------------------------------
✗ Видеть визуальный результат
✗ Работать с файлами напрямую (только через инструменты)
✗ Запоминать контекст между сессиями

6.3 Агент предупредит если
--------------------------------------------------------------------------------
⚠ Вы просите удалить важные файлы
⚠ Изменения могут сломать проект
⚠ Файл не найден или недоступен

8. ЕСЛИ КОНТЕКСТ ПЕРЕПОЛНЕН (100% used)
================================================================================

8.1 Признаки переполнения
--------------------------------------------------------------------------------
- Агент медленнее отвечает
- Начинает "забывать" детали проекта
- Появляется предупреждение в интерфейсе

8.2 Что делать
--------------------------------------------------------------------------------
ВАРИАНТ 1: Завершить текущую работу
1. Попроси агента сохранить все изменения
2. Начни новую сессию
3. Агенту: "Продолжи с того места где остановились"

ВАРИАНТ 2: Использовать отдельный агент (рекомендуется)
1. Запусти: opencode
2. Дай краткую задачу: "Сделай X"
3. Заверши сессию
4. Повтори для следующей задачи

ВАРИАНТ 3: Попроси агента подытожить
Агенту: "Сохрани текущий прогресс и что осталось сделать"

8.3 Как избежать переполнения
--------------------------------------------------------------------------------
✓ Ставь четкие, короткие задачи
✓ Не проси "сделай всё сразу"
✓ Разбивай большие задачи на части
✓ После каждой задачи - новая сессия

8.4 Пример работы с большим проектом
--------------------------------------------------------------------------------
Сессия 1: "Создай структуру компонентов"
Сессия 2: "Добавь стили для компонентов"
Сессия 3: "Подключи JSON данные"
Сессия 4: "Протестируй и исправь баги"
